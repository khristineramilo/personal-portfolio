# My Professional Portfolio

This is my first React application built for **COMP229 - Web Application Development**. It showcases my skills, projects, and background.

## 🛠️ Tech Stack
- **Framework:** React.js
- **Styling:** CSS3 (with Glassmorphism and Animations)
- **Routing:** React Router DOM
- **Deployment:** Netlify

## 📁 Project Structure
- `src/components`: Contains individual pages (Home, About, Projects, etc.)
- `src/assets`: Stores images and project screenshots.
- `public/`: Stores the downloadable resume and favicon.

## ⚙️ How to Run Locally
1. Clone the repository
2. Run `npm install` to download dependencies
3. Run `npm start` to launch the development server
